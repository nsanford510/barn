# NOO-69: 1468 8th St, Oakland

**APN:** 004-0081-010-00  
**Verdict:** `likely_vacant`  
**Confidence:** 0.90  
**Vacancy start / duration:** Unknown. The earliest clear evidence reviewed that calls the site a cleared lot is an MLS listing dated 2025-11-06. No evidence establishes the start date or uninterrupted vacancy through the present.

## Finding

Evidence supports that the parcel is likely vacant as a site: a 2025-2026 property record gives it Alameda County use code 1000 (vacant residential land), and an MLS-syndicated listing dated November 6, 2025 describes it as cleared, unimproved land. Oakland separately verified a blight condition at the address in May 2019. The city report documents overgrown vegetation and a fallen fence, but does not say the property was vacant. The county classification is for assessment purposes and is not a continuously updated occupancy check. Taken together, these sources support the likely-vacant verdict, but do not establish an exact vacancy start or continuous duration.

## Evidence

[Alameda County's use-code list](https://propinfo.acgov.org/UseCodeList) defines code 1000 as “Vacant residential land, zoned 4 units or less.” The county warns that use codes are intended for assessment and are not continuously updated.

2. **MLS land listing (listed 2025-11-06).** [Weichert's syndicated page](https://www.weichert.com/131540909/) identifies MLS 41116859 as “Lots and Land,” “Unimproved Land,” with a 0.08-acre lot and describes the site as a cleared, level parcel. Listing status can change, and the available page does not establish today's condition or a continuous vacancy period.

3. **Oakland blight inspection (May 2019).** The [City of Oakland's Q4 2019 code-enforcement report](https://www.oaklandca.gov/files/assets/city/v/1/planning-amp-building/documents/ce/bce-reports/code-enforcement-quarterly-report-inspection-count-q4-april-1-june-30-2019.pdf) records case 1902122 for 1468 8TH ST. ## Duration assessment

The evidence does not support a vacancy start date or a claim that vacancy was continuous. The 2019 blight observation alone does not establish that no one occupied the site. The 2025-11-06 listing and 2025-2026 assessor classification support vacant-land status by that period, but neither establishes how long that condition had existed or that it persisted uninterrupted. Record start and duration as unknown.
