## Rationale

An Alameda County Environmental Health site development presentation dated May 3, 2016 describes this exact address as a 10,000-square-foot vacant, unpaved parcel. It calls it a former service station. Oakland's February 2026 planning attachment lists the parcel with County use code 1000; Alameda County's vacant land survey defines that code as Residential Vacant. A community history reports that the building was demolished on January 29, 2015 for environmental cleanup. Together these support a vacant parcel, not an occupied dwelling. The current code is an assessor classification, not direct onsite observation, so exact physical condition and uninterrupted vacancy are not proven.
